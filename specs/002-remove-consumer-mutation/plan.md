# Implementation Plan: Remove Consumer-Project Mutation

**Branch**: `mvp` | **Date**: 2026-08-02 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/002-remove-consumer-mutation/spec.md`

## Summary

Delete the legacy consumer-file mutation model end-to-end. Native and catalog planners will emit only
complete generated artifacts plus typed usage descriptors. Web branding will publish a complete owned
manifest and describe HTML/SEO/static-host actions. Native plans will omit Android/Xcode update tasks
and describe caller setup. Generation, cleanup, verification, reporting, composition, schemas, public
exports, tests, demos, and documentation will operate without adapters, receipts, gateways, or Git
metadata writes.

## Technical Context

**Language/Version**: TypeScript 6.0.3, Node.js >=22.12, ESM/NodeNext

**Primary Dependencies**: Existing planning/materialization/publisher contracts; no new dependency

**Storage**: Complete owned outputs plus `.assetloom` cache/manifest/lock/pending state; obsolete
integration receipt files are ignored and never interpreted

**Testing**: Vitest 4.1.10, strict TypeScript, ESLint, schema validation, package smoke

**Target Platform**: Cross-platform Node library/CLI; Android/iOS/web outputs with caller-owned setup

**Project Type**: Asset compiler and whole-file publisher

**Performance Goals**: Removal must not add rendering work; unchanged generation remains zero-write

**Constraints**: No mutation compatibility layer; stable `LOOM_` diagnostics; preserve complete
generated bytes where non-conflicting; no new resource types; Expo excluded

**Scale/Scope**: Delete/rewrite all runtime mutation paths in the single current package before the
workspace extraction feature

**Structure Decision**: Remove capabilities in dependency order: define descriptor contracts, change
planners, simplify executors/APIs, then delete ports/adapters/state and update verification/reporting.
No compatibility package is created. Native content serializers may retain complete resource-bundle
generation but all manifest/pbx mutation functions are removed.

## Phase 0: Research Decisions

See [research.md](research.md). Decisions: descriptors attach declaratively to plan artifacts; the
result builder de-duplicates them; generated web manifests are ordinary whole files; former native
project paths are rejected schema properties; obsolete receipts are ignored; verification never
opens consumer integration files.

## Phase 1: Design and Contracts

See [data-model.md](data-model.md), [usage-descriptors-v1.md](contracts/usage-descriptors-v1.md), and
[quickstart.md](quickstart.md). Post-design constitution status remains PASS.

## Implementation Phases

1. Add sentinel/architecture/descriptor tests and types.
2. Replace web integrations with complete manifest output and web descriptors.
3. Remove native update tasks and add native descriptors; remove project-path schema fields.
4. Simplify execution, generation, cleanup, verify, report, and recovery to owned artifacts only.
5. Delete adapters/receipts/gateways/Git manager, remove exports/tests/docs/config, and run searches.
6. Run full verification and packed-consumer smoke tests.
