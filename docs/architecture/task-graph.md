# Generation task graph

```text
configuration files
  +-- parse each file
  +-- merge in CLI order
  +-- validate schema and native paths
  `-- resolve and hash source dependencies
       |
       +-- Android
       |    +-- legacy and round launcher bitmaps
       |    +-- adaptive foreground/background/monochrome bitmaps
       |    +-- adaptive icon XML
       |    +-- notification bitmaps and color
       |    +-- day/night splash bitmaps, drawable, colors, themes
       |    `-- caller usage descriptors
       |
       `-- iOS
            +-- light/dark/tinted 1024 px icons OR opaque .icon copy
            +-- app-icon Contents.json
            +-- day/night launch images and named color
            +-- launch storyboard
            `-- caller usage descriptors

all generated bytes
  +-- destination conflict preflight
  +-- content-addressed cache
  +-- atomic publish if changed
  +-- stale owned-file cleanup
  `-- manifest and recovery-state publish
```

The planner sorts by destination for stable output. A target-filtered run keeps
the other target's manifest entries and generated resources intact.
